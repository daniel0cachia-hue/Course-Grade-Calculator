How to Use the Course Grade Calculator

Enter each of your assignments, exams, or grade categories along with their weight (how much they count toward your final grade) and the score you received. Weights should add up to 100%, but if you haven't entered everything yet, the calculator automatically assumes the rest of your class makes up the difference.

Hit Calculate Grade to see your current standing. If you have ungraded work remaining, you'll also see your current performance on graded work only so you always know exactly where you stand. Use What Do I Need to Pass? to find out the average score you need on remaining assignments to hit your target grade.

Use Save Course to store the setup currently in your table, and My Courses to browse, organize, sort, and reload saved courses whenever grades come in. Sort By changes the order of top-level folders and classes not inside folders; items inside a folder stay ordered by most recent activity so the thing you just edited or loaded rises to the top of that folder.

Use Share Calculator to copy a short message and the website link so you can send the calculator to someone else.

How to Use the Grade Calculator

A weighted course grade calculator. Enter your assignments, their weight (how much they count toward your final grade), and the grade you received. Leave a grade blank if it hasn't been scored yet. Your classes and preferences are automatically saved and will be there when you return.

Calculating Your Grade

Fill in each assignment name, weight, and grade, then click Calculate Grade. If some grades are blank, the results show your current grade based on completed work, the minimum final grade if remaining work scores 0%, and a full grade breakdown.

If every grade is entered, the duplicate minimum card is hidden and the button changes from What Do I Need to Pass? to Did I Pass My Class?. The popup checks your final grade against the target you type.

The What do I need to get a __% ? box updates live and shows the average needed on remaining assignments. Use the copy buttons to copy either a grade summary or passing summary.

Keyboard Navigation

Tab or →
Move right to the next field. Wraps to the first field of the next row.
←
Move left to the previous field. Wraps to the last field of the row above.
↑ / ↓
Move up or down one row, staying in the same column.
Enter
Move down one row. At the bottom, wraps to the top of the next column. If all weights and grades are filled, triggers Calculate Grade automatically.
Backspace
On an empty field, moves up to the previous row (instead of deleting).
Esc
On an empty row, deletes that row and moves focus to the nearest row.
Ctrl + Z
Undo the last change. Also available as the Undo button in the toolbar.

Saving Courses

Click Save Course to store the setup currently in your table, or My Courses to open the course manager. It stores assignment names, weights, grades, folder location, and the active-course editing state. When you rename a saved class or folder, save table edits, or load a class inside a folder, that item moves to the top of its folder.

Load
Replaces the current table with that course's saved data. A banner appears at the top showing which course you're editing.
Save
While a class is loaded, use this banner button to overwrite it with your latest edits.
Click the pencil icon on any saved course to rename it inline.
Unlink
Disconnects the current table from a saved course without deleting the save.

Search & Folders

Use search in the course manager to find saved courses or folders. Searching a folder name shows that folder without opening it. Searching a course name opens whatever folders are needed so the matching course is visible. Use Sort By to order only top-level folders and classes not inside folders by recently edited, alphabetical, date added oldest, or date added newest. Contents inside folders automatically stay sorted by most recent activity.

Folder
Creates a named folder to group related classes together (e.g. "Fall Semester", "Year 1"). Folders can be nested inside other folders for deeper organisation.
Sort
Changes the order of top-level folders and classes not inside folders. It does not override the inside of a folder, where recently edited classes and folders move to the top.
Click the move icon on a folder header to place it inside another folder, or move it back to the top level.
Click a folder header to expand or collapse it and see the courses inside.
Click the move icon on any class to assign it to a folder, or remove it from its current folder.
Click the pencil icon on a folder header to rename it inline.
